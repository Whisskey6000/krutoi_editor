# KrutoiEditor

Консольный текстовый редактор с поддержкой Markdown и автотестами на Python.

## Структура репозитория по веткам:
- `pr2` — Исходный код KrutoiEditor (TUI приложение и стили без комментариев).
- `pr3` — Функции валидации и арифметики, покрытые unit-тестами на pytest (без комментариев).
